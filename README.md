# 学位英语冲刺站

这是给零基础准备 12 月学位英语考试的本地学习项目。

## 页面

- `index.html`：基础学习路线
- `words.html`：基础词汇 + 四级/六级方向词族
- `practice.html`：智能练习，支持英译汉、汉译英、听音默写、错题本和发音
- `words.html` 内已整合：相近词/词根词族、雅思方向词汇、规则动词 `-ed` 和不规则动词变化
- `must.html`：每天固定必背任务
- `phrases.html`：固定搭配
- `sentences.html`：短句和作文句
- `adverbs.html`：副词总表
- `grammar.html`：语法口诀和考试重点
- `cloze.html`：完形填空搭配
- `tenses.html`：16 大时态

## 每天学习

1. 背 40 个单词。
2. 背 10 个固定搭配。
3. 读 10 个短句。
4. 学 1 个语法点。
5. 复习昨天内容。

## 智能练习

打开 `practice.html`，可以选择：

- 看英语写中文
- 看中文写英语
- 听发音默写英语
- 只练错题

错题会自动保存在浏览器本地，下次打开还在。

## 背词顺序

先背基础高频词，再背考试抽象词，最后背六级方向词族。不要一开始追求所有生僻词，先保证阅读里反复出现的词能认出来。
